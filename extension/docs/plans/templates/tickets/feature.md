# Feature Ticket Template

```yaml
id: FEAT-NNN
title: Short capability title
type: feature
status: draft
priority: high
phase: EN
created: YYYY-MM-DD
updated: YYYY-MM-DD
dependencies: []
```

## Goal

Describe the user-visible or maintainer-visible outcome.

## Scope

In scope:

- Item.

Out of scope:

- Item.

## Linked Requirements

| Requirement | Source |
| :--- | :--- |
| Requirement tag or name | Relative path |

## Linked BDD

| Feature | Scenario |
| :--- | :--- |
| Relative path | Scenario name |

## Child Tickets

| Ticket | Title | Status |
| :--- | :--- | :--- |
| `TASK-NNN` | Task title | `open` |

## Acceptance Criteria

- [ ] Child tickets are terminal.
- [ ] Phase gate passes.
- [ ] Tests and docs are updated.
- [ ] Retrospective is appended.
